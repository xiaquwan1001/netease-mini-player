# N1 — EQ 两项(导入校验 + 图表高度 +15%)

日期: 2026-11-18 ｜ 车道: N1 ｜ 状态: 完成(单轮收尾)

## 1. EQ 导入接入曲线校验

**问题**: 导入曲线只走纯 Dart 的 `parseParametricEq`, 而 `ui/lib/src/audio_tuning.dart`
的 `validateEqProfile`(Rust `eqProfileValidate` 的唯一入口)零调用 —— 校验口径与实际
生效(Rust/Kotlin 解析同一份文本)可能漂移。

**做法**:
- 新增 `ui/lib/src/eq_import.dart`: `checkEqImportText(text, {validate})`
  - 权威校验先问 Rust(`validateEqProfile` → `ncm-domain::EqProfile::parse`);
    Rust 的 `FfiError.detail` 本身就是 "第 N 行: 原因", 原样展示, Dart 侧不再另写规则;
  - 只有 FFI 根本不可用(测试环境无 cdylib / 平台不支持)时才用 `parseParametricEq` 兜底;
  - 空文本直接拒绝(`请输入曲线文本`);
  - `validate` 参数是测试注入缝, 避免为一个纯逻辑再拉一次 FFI。
- `settings_audio_page.dart`: 两道门
  - 对话框 `_submit` 改为异步: 先校验, 不通过就在弹窗内既有的错误行(红字)回显,
    **不 pop、不落盘**, 期间 `_busy` 禁用「导入」防连点;
  - `_importEq` 是落盘的唯一入口, **落盘前再校验一次**(以后加「从文件读取」也不会绕过去),
    失败只 toast 不写 `AppSettings`; 成功时用 Rust 的 `activeFilters` 提示
    "已导入自定义响度曲线(生效 N 个滤波器)"。

**说明**: 代码里目前只有"粘贴文本"一条入口(没有文件选择实现), 所以文件路径没有可接线的地方;
校验门放在落盘边界, 将来接文件导入时自动覆盖。

## 2. 曲线/柱状图高度 +15%

`eq_curve_chart.dart` 新增三个常量(两张图内部都按 `LayoutBuilder` 父约束铺满, 没有写死的内容高度,
所以只改基数一处即同步生效):

- `kEqPanelBaseHeight = 232`(放大前的实际值)
- `kEqChartHeightScale = 1.15`
- `kEqPanelHeight = 232 × 1.15 = 266.8`

设置页 `SizedBox(height: kEqPanelHeight)`, 页面仍在 ListView 里 ⇒ 300dp + 1.25 字号只多滚动, 不竖溢
(`s5_audio_settings_page_test` 的窄屏用例 + `settings_narrow_overflow_test` 全绿)。

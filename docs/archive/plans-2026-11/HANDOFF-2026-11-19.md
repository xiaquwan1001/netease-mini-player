### 1.1 夜间回执(buffering-download 已完成, 2026-11-18 深夜)

`buffering-download` **已完成**(自报: Rust **349/0**(313→349, service 227 + playback 47) · clippy 0 · fmt 干净 · analyze 0 · Kotlin 单测 **10**(7+3) · lint 0 error · token/row-padding/write-guard OK):
- **强制 https**(只升 `*.126.net`/`*.163.com`, 去显式 `:80`, 判定可注入): Rust `cache.rs` 的 `prefer_https*`/`is_netease_host` + Dart `playback.dart` 的 `preferHttpsStreamUrl`, **桌面 `play()` 也升级了**(以前把明文直链直接交给 Rust)。
- **下载器**: 单例 `reqwest::Client`(UA 取 `identity::platform_profile().ua` 单一来源、`Referer`、connect 10s、读间隔 20s)+ 首包 15s 限时 + `classify_http`(非 2xx 判失败, 2xx 但首包 `text/html` = 劫持特征 ⇒ 可重试); 下载重试**恰好一次**。
- **Android 缓冲**: 新纯 Kotlin `AudioBufferPolicy`(15s/50s/1s/**2s**) + `DefaultLoadControl`(重缓冲恢复 5s→**2s**, 这是"卡顿体感"的直接旋钮), `handleAudioFocus=true` 与 cache 配置未动。
- **桌面判死**: 修掉 `GrowingFile` 真实缺陷 —— 计时原本从"打开文件"起算(慢网 90s 后偶发假 EOF), 改为每读到字节刷新 `last_data`; stalled 返回 `TimedOut` 而非 `Ok(0)`(不再静默切歌); 阈值可配 `NCM_GROWING_STALL_SECS`。
- **缓存键**: `{track_id}.{level}.{ext}` + **先新键后回退旧键**(不清缓存), 音质经 `song_url → remember_level` 旁路传入(不改 FFI 签名); 迁移期"换档第一次仍可能命中旧文件"已写进注释并打日志。

## 6. 环境坑(今晚新增)

- **wrangler 会读 `HTTP(S)_PROXY`** ⇒ 本机代理下 `fetch failed`。部署/查询前先 `env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy`。
- **`*.workers.dev` 大陆直连超时**(实测 20s), 经代理正常。
- `pkill -f "wrangler dev ..."` 会**杀掉自己的 shell**(命令行里含同样字符串) —— 用 `pgrep` 先看清再按 pid 杀。
- `tools/diag-worker/.dev.vars`(0600, gitignored) 里有 PAT; 轮换后记得同步它或直接删。

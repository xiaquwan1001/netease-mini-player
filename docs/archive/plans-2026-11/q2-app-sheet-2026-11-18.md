# Q2 / U-03 统一浮层入口(app_sheet.dart)  — 2026-11-18

## 目标
把散落的 `showModalBottomSheet` / `showDialog` 收到单一入口:
`ui/lib/src/app_sheet.dart` 的 `showAppSheet` / `showAppDialog`, 并用
`tools/check-sheet-entry.sh` 把「直接调用」变成红灯。

## 现状审计(改动前, `rg -n "showModalBottomSheet|showDialog" ui/lib/src`)
- 命中 44 行, 其中 6 行是注释/文档里提到名字(layout.dart / album_preview.dart /
  sheet_header.dart / popup_routes.dart), **真实调用 38 处**:
  sheet 20 处 + dialog 18 处, 分布 28 个文件。
- sheet 参数分布(20 处):
  | 参数 | true | 未写(= 默认 false/null) |
  |---|---|---|
  | `isScrollControlled` | 13 | 7 (digital_album_page, detail_shared, settings_view ×2, song_action_wiring ×2, ...) |
  | `showDragHandle` | 19 | 1 (song_wiki) |
  | `useSafeArea` | 0 | 20 (没人用过; 需要时各自在 builder 里包 `SafeArea`) |
  | 路由级高度 | 0 | 20 —— 高度全部是 builder 内的
    `SizedBox(height: MediaQuery.sizeOf(context).height * 0.6/0.7/0.75/0.8)`
  | `barrierDismissible`(dialog, 18 处) | 17 默认可关 | 1 处显式 `false`(cloud_page 上传中) |
  | `barrierColor`(dialog) | — | 1 处 `Colors.black`(cover_art 全屏看图) |
- 结论: **多数派默认 = isScrollControlled: true / showDragHandle: true**
  (与 v0.22.1 的 `buildAppSheetRoute` 默认一致), 少数派在调用点显式写出。
- `useSafeArea` 全仓 0 使用 ⇒ 入口默认 false 与现状逐处等价, 不迁移任何 SafeArea。
- 高度是 builder 内的事 ⇒ 入口提供 `initialHeight`(屏高比例)只给**新代码**用,
  本批迁移**不碰**任何尺寸包裹(逐字不变)。

## 落地
1. `ui/lib/src/app_sheet.dart`
   - `showAppSheet<T>(context, {builder, isScrollControlled=true, showDragHandle=true,
     useSafeArea=false, initialHeight, settings})` —— 内部 `Navigator.push(buildAppSheetRoute<T>(...))`,
     因此天然进 U-01 的 `PopupRoute` 登记表, 能被 `dismissAllPopups()` 收起。
   - `showAppDialog<T>(context, {builder, barrierDismissible=true, barrierColor,
     useSafeArea=true, settings})` —— 转发 `showDialog`(DialogRoute 也是 PopupRoute,
     同样进登记表), 但调用点只允许经此入口。
   - 文件头写清「新代码一律走这两个入口; 直接调 showModalBottomSheet/showDialog 视为回归」。
2. `ui/lib/src/popup_routes.dart`: `buildAppSheetRoute` 增 `bool useSafeArea = false`
   (透传 `ModalBottomSheetRoute.useSafeArea`; 默认值与 Flutter 一致 ⇒ 现有两个调用方零变化)。
3. `tools/check-sheet-entry.sh`: 纯 rg + 退出码, 白名单
   `ui/lib/src/app_sheet.dart` / `ui/lib/src/popup_routes.dart` / `ui/test/**`;
   带 `--self-test`(临时插一处直接调用, 断言红灯后退 0)。
4. 迁移: 除排除名单(podcast_detail_page / mine_view / app_shell / home/**)外全部换入口,
   每处逐字保留返回类型/泛型/barrierDismissible/高度/isScrollControlled/useSafeArea。
5. 新增 `ui/test/app_sheet_entry_test.dart`; 既有 sheet/dialog 测试不改断言(若必须改,
   在提交说明里标注「行为未变只换了入口」)。
